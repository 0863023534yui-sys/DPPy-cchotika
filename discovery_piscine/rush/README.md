# == INTRODUCTION ==
This progam runs a Snake & Ladder game which consist of 2 players take turn on a Dice 6 to progess. The first player to reach the final tile wins the game.
## == Components ==
### 1. The board
The board is a 5x5 grid that contains 25 tiles (1-25) with the final tile serve as win condition. This make for quicker demonstration and easier to program.
## 2. Snake & Ladder
The board will contain atleast a snake and a ladder:
Ladder: Ascend player closer to the goal
Snake: Descend player further away from the goal
